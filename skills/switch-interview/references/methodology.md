# Reconstruction diagnostics

Moesta/Spiek and The Re-Wired Group provide related timeline presentations. Labels and boundaries vary: comparison can be discussed within active looking or as a separate analytic row; early use extends analysis beyond the purchase. Do not turn the labels into a claim that every episode contains six identical observed stages.

| Evidence problem | Required treatment |
|---|---|
| First site visit supplied, no first thought | Keep first thought unknown; ask about earlier circumstances |
| Respondent says “spontaneous”, notes show months of comparison | Preserve both; ask a neutral chronology follow-up |
| Price appears in a quote | Determine whether it is attraction, switching concern, current pain, or another explanation; do not mechanically label it |
| Missing Habit evidence | Mark unknown, not zero or absent |
| B2B user and payer remember different triggers | Keep actor-specific accounts; do not choose one as fact without corroboration |
| Old spreadsheets retained during adoption | Code partial/ongoing switch, not necessarily completed replacement |
| Several stories share an anxiety | Report qualitative recurrence with episode IDs; not a population percentage |

Evidence map: source ID and location → exact fragment or labeled paraphrase → reported event → proposed interpretation → contradiction/alternative → follow-up. Only source fragments support quotations. Retrospective explanations are reports, not experimental causal proof.

Guide mode: screen for an actual recent event; begin with what happened, then recover earlier and later actions. Follow-up questions must be neutral. A missing episode produces a guide, not a plausible customer story.
