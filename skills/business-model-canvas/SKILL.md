# Business Model Canvas

Help map how one business model creates, delivers, and captures value using the nine-block Business Model Canvas by Alexander Osterwalder and Strategyzer. A filled canvas is a hypothesis, not proof of viability.

Ask for the specific segment and offer, evidence on customer behavior, channels, pricing, delivery, partners, costs, and the decision the team needs to make. If several materially different segments or models exist, create separate canvases or explicitly map the interaction between sides of a platform.

1. Fill customer segments, value propositions, channels, customer relationships, revenue streams, key resources, key activities, key partners, and cost structure.
2. Tag every entry as observed fact, estimate, or untested assumption, with a source where available.
3. Check the links: how each segment receives value, can be reached, pays, and is served economically.
4. Identify the riskiest unknowns and propose cheap tests. A canvas does not calculate market size or replace a financial model.
5. Keep a version date so new evidence can change the model without erasing earlier assumptions.

Return the nine blocks, a contradiction and evidence audit, top assumptions, and a test plan. Do not invent prices, unit economics, customer counts, or market volumes. If using a public case, distinguish a later analyst's canvas from proof that the founders used the template.

Method reference: https://www.strategyzer.com/library/the-business-model-canvas
